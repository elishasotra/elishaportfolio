# Elisha Sotra — Portfolio

Dark, futuristic React/Vite portfolio for Elisha Sotra, focused on AI, software development, web design, automation and interactive products.

## Stack

- React
- Vite
- Framer Motion
- Lucide React
- Plain CSS

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run lint
npm run build
```

## Notes

The portfolio is a static frontend. JARVIS is presented as a visual concept/showcase; it does not contain the actual backend, voice recognition, notifications, authentication, or AI engine.

Project content and links are kept in `src/data/projects.js`, while project-specific system visuals live in `src/Projects.jsx`.
